# 灰烬岗哨 · 3D 桌面切片

《灰烬岗哨》的 **3D 桌面版纵向切片**：同一个剧本、同一套 5e 规则，把原来的 2D 文字演示变成一张可以转、可以点的桌面。不是完整游戏，也不是换皮——探索、社交、战斗、短休、成长五幕都在里面，但它只跑这一幕。

> 剧本：[`scenario.md`](./scenario.md) · 2D 文字版：<https://chehua11agent.github.io/superagent-test/prototype/ashen-watch/>

## 打开

```bash
cd prototype/ashen-tabletop
python3 -m http.server 8080
# http://127.0.0.1:8080/
```

无构建、无运行时依赖；three.js r160 在 `vendor/`（MIT，见 `vendor/THREE-LICENSE.txt`）。

## 这一版有什么

| 系统 | 实现 |
| --- | --- |
| **3D 桌面** | 雪地岗哨：门楼、塔、雉堞、旗、火把、火盆、断车、补给箱、焦尸、拖痕、枯树、雪与余烬；可旋转 / 缩放 |
| **3D 骰子** | 桌上两枚 d20，带 1–20 面数字；检定、攻击、豁免都真的在桌上滚，优势 / 劣势滚两枚取高 / 低 |
| **角色 / 指示物** | 布兰、薇拉、奥伦、艾达、灰烬骑士、两只灰烬猎犬；点击看 HP / AC / 攻击 / 特性，战斗中点敌人切换目标 |
| **技能卡** | 每个角色自己的动作卡 + 闪避 / 治疗药水 / 火油 / 结束回合；点卡使用，点卡角 `i` 看完整说明与规则出处 |
| **剧本推进** | 探索三处调查点（完成两处进入）→ 艾达社交（村徽 / 说服 / 洞悉 / 威吓 / 硬闯）→ 灰烬骑士战斗 → 短休 → 升级 / 尾声 |
| **5e 规则** | d20 + 调整值 vs DC；先攻、AC、攻击、伤害、暴击、优势 / 劣势、豁免、偷袭、法术位、死亡豁免、短休生命骰、XP / 升级 |
| **规则书** | 右上「规则书」抽屉：检定 / 战斗 / 死亡与短休 / 这一幕 / 来源与许可 |
| **移动端** | 竖屏机位；队伍横条、底部手牌；剧情面板可「收起 / 展开」，收起后看整张桌面与骰子 |

## 操作

- 拖拽旋转，滚轮 / 双指缩放。
- 点场景里的**发光调查点**，或右侧剧情选项。
- 点**角色 / 敌人 / 道具**看说明；战斗中点敌人切换目标。
- 点手牌使用动作；卡角 `i` 看说明。
- 点桌上骰子 / 「自由掷骰」随便滚一枚 d20。
- `Esc` 关闭弹窗 / 规则书。

## 建模与技能

这一版应用了本机已安装的游戏技能：

- **`create-game-assets`**：先定 art direction / 资产清单 / 3D 管线；模型全部用 three.js 基本几何体程序化搭建，没有引第三方模型或贴图。
- **`rpg`**：探索 → 遭遇 → 奖励 → 成长的核心循环；检定、战斗、短休、升级按剧本数据落。
- **`game-ui-ux`**：桌面 HUD / 手牌 / 剧情面板的布局与断点；移动端可收起剧情。
- **`game-feel`**：骰子落桌、命中飘字、短促镜头震动、火光闪烁。

角色、建筑、道具都是低多边形程序化模型；旗帜、数字骰面、火光、雪是 canvas 贴图 / 粒子 / 自发光。没有 Blender、glTF 或外部素材。

## 已知边界

- **只有一幕**：3 名角色、1 条主线、几套社交分支；不是完整战役。
- **没有自由行走 / 格子 / 掩体**：5e 本身是 theater of the mind；这里的指示物表示站位与目标，不表示距离。
- **没有存档 / 多人 / DM 模式**；刷新重开。
- 部分职业特性简化：冠军 19–20 重击、盗贼偷袭 / 隐匿 / 协助已接；塑能师只做火焰箭与魔法飞弹。
- 材质是纯色 + 平直着色，没有 PBR 贴图；低端手机可能掉帧（`?qa=1` 可关阴影，仅供调试）。
- 还没有接进现有 2D 游戏的入口；这是给方向确认的 3D 伴生切片，确认后再决定怎么接。
