# 词塔 · Word Tower

一个画面简约的肉鸽卡牌小原型：**五层、一副越打越厚的词卡、约五分钟一局**。每张牌是一个 CET-4 单词；敌人是「怀疑」「阴影」「遗忘」这些让词溜走的东西。

这是用来试手感的可玩切片，不是完整游戏。

## 直接打开

`index.html` 是无构建的静态页面，双击即可在浏览器里玩（也可以起一个静态服务器）：

```bash
python3 -m http.server 8000
# http://127.0.0.1:8000/
```

无外部字体、图片、音频或网络请求；手机和桌面都做了布局适配。

## 这一版有什么

- **5 层路线**：普通战斗 → 分岔（战斗 / 篝火）→ 精英 → 分岔 → 首领。
- **战斗**：每回合 3 点费用，抽 5 张，点击手牌打出；结束回合后敌人按头顶的意图行动。格挡在你下回合开始时清零。
- **构筑**：战斗后三选一加一张词卡；篝火可以休息（回血 + 从灰烬里捡一张随机词卡）或打磨一张牌。
- **敌人**：3 种普通怪、1 个精英「沉默」、1 个首领「遗忘」；生命过半后首领会加深攻击。
- **防拖回合**：第 10 回合起敌人失去耐心，每回合攻击 +1。
- **20 张词卡**：sharp / shelter / guide / balance / prepare / repair / crash / edge / escape / signal / reflect / survive / risk / trust / courage / rise / release / tide / choose / harbor。
- 合成音效、伤害飘字、卡牌悬浮、敌人受击抖动；支持 `prefers-reduced-motion`。

## 操作

| 操作 | 方式 |
| --- | --- |
| 打出手牌 | 点击卡牌，或数字键 `1`–`9` |
| 结束回合 | 「结束回合」按钮，或 `E` / 空格 |
| 查看牌组 | 顶栏「牌组」，或 `D` |
| 关闭面板 | `Esc`，或点面板外 |
| 开始游戏 | 「开始攀登」，或 `Enter` |

## 文件

```
index.html     页面结构
styles.css     纸感/墨/朱红的视觉与响应式布局
game.js        卡牌与敌人数据、流程、战斗结算、音效
screenshots/   验收截图（before / after）
```

卡牌是数据驱动的：`CARDS[id].fx` 是一组 `{op, n}`，`upFx` 是打磨后的版本；伤害、格挡、抽牌、加费、回血都是同一个小解释器处理的。要加一张牌，复制一条数据即可。

## 已知边界

- 没有存档 / 继续游戏，刷新即重开。
- 没有商店、事件、多幕、遗物、状态效果；目标选择固定为单个敌人。
- 单词只作卡面与命名，尚未接入复习算法、发音或学习统计。
- 数值是按「五分钟能走完」的范围粗调的，不是平衡后的正式版本。
