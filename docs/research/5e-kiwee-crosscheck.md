## 0. 一页结论

| 问题 | 结论 |
| --- | --- |
| 规则内容对得上吗？ | 对得上。词表里的战斗动作、9 个状态与豁免的规则说法，和站内 PHB（2014）条目一致（使用物件一条措辞可再收紧，见 §3）。 |

| 页码对得上吗？ | 对不上。站内 `page` 是英文原版页码；我们 PHB 复盘用的是 288 页民间汉化 PDF 的书页，两者不可互换。 |

一句话：**规则没矛盾，译名、版本、页码三套基准对不上**；拿站内条目核对 2014 玩法时，要认 `PHB` 来源，不要用默认的 2024 条目。

## 1. 站点是什么

- 5etools 的非官方中文镜像（首页自述），首页说明「5etools中文站完全开源」，GitHub 链接指向 `tjliqy/5etools-cn` 的 `cn2.0` 分支；含 2014 与 2024 两代核心书、冒险模组与扩展。
- 2014 条目的数据字段 `translator` 为「不全书」，即 5e不全书汉化组译文；这是爱好者翻译，不是威世智官方中文版。
- 首页自述「当前版本仅为测试Demo版，并未完成全部的翻译和校对工作」；内容「仅供学习、交流、参考使用，不用于任何商业用途」，翻译内容按页面链接的 CC BY-NC-SA 4.0 授权。
- 对工程最有用的是机器可读数据：`/data/actions.json`、`/data/skills.json`、`/data/conditionsdiseases.json`、`/data/spells/spells-phb.json` 等，每条带 `ENG_name`、`source`、`page`，多数带 `translator` 字段，比抓 HTML 稳定。

## 2. 差异清单

### 2.1 译名差异（8 处）

两套都是民间汉化：我们手边是 288 页 PDF 的译文加词表里的常见叫法，站内是 5e不全书汉化组的重译，译名不统一是必然的。

| 英文（`ENG_name`） | 我方现有写法 | 站内 2014 | 站内 2024 | 出处（站内页码） |
| --- | --- | --- | --- | --- |
| Acrobatics | 杂技 | 特技 | 特技 | 技能：PHB p.176 / XPHB p.14 |
| Dodge | 闪避 | 回避 | 回避 | 动作：PHB p.192 / XPHB p.366 |
| Dash | 冲刺 | 疾走 | 疾走 | 动作：PHB p.192 / XPHB p.365 |
| Help | 帮助 | 协助 | 协助 | 动作：PHB p.192 / XPHB p.368 |
| Ready | 准备 | 预备 | 预备 | 动作：PHB p.193 / XPHB p.372 |
| Use an Object | 使用物品 | 使用物件 | —（2024 改为「操作」Utilize，p.377） | 动作：PHB p.193 |
| Frightened | 恐惧 | 恐慌 | 恐慌 | 状态：PHB p.290 / XPHB p.367 |
| Blinded | 失明 | 目盲 | 目盲 | 状态：PHB p.290 / XPHB p.361 |

补充两条不算错、但值得统一的：

- `Grappled`：站内 2014 的状态名是「受擒」（p.290），动作名仍是「擒抱」（p.195）；我们词表只在叙事里用「擒抱」，没有把「受擒」当状态名。
- `AC` / `HP`：站内写作「护甲等级」「生命值」；我们正文用英文缩写，属缩写差异。

对得上的（无需改）：六大属性，运动、隐匿、洞悉、调查、游说、欺瞒、察觉、威吓，攻击、撤离、躲藏、搜索、借机攻击、先攻、优势、劣势、豁免，以及中毒、魅惑、麻痹、耳聋、力竭、倒地、束缚、隐形等状态。

### 2.2 版本差异（2014 vs 2024）

- 同名条目在站内有两份数据：2014（`source: PHB`，一般带 `reprintedAs`→2024，页面标「过期资源 ʟ」）与 2024（`source: XPHB`）。站点前端源码 `/js/parser.js` 把 PHB/DMG/MM 2014 列进 `SOURCES_LEGACY_WOTC`，把 XPHB/XDMG/XMM 当当前核心。
- 与我们有直接关系的规则变化（若误读 2024 条目，会和 2014 设计对不上）：
  - **躲藏**：2014 是敏捷（隐匿）检定对抗被动察觉；2024 改为固定 DC 15 的敏捷（隐匿）检定，成功获得「隐形」状态。
  - **力竭**：2014 六级递进（属性检定劣势、速度减半等）；2024 每级 −2 D20 检定、速度 −5 尺，6 级死亡。
  - **使用物件**：2024 取消该动作，改为「操作」（Utilize）；同时新增「影响」（Influence）、「研究」（Study）、「魔法」（Magic）动作。
  - **擒抱**：2014 是独立动作（p.195）；2024 并入「徒手打击」选项。
- 我方基准：词表 §0 写明「DnD 5e（2014）」；README 写「按 5e 规则」；PHB 复盘的对象是 2014 PHB 民间汉化。因此查站内时应选 `PHB` 条目，`XPHB` 条目只作扩展参考。

### 2.3 页码差异

- 站内 `page` 是英文原版页码：动作 PHB p.192–193、状态 PHB p.290–292、Acrobatics p.176；2024 为 XPHB p.14 / p.361–377。
- 我们 [`phb-story-dm-review.md`](phb-story-dm-review.md) 用的是 288 页民间汉化 PDF 的书页（PDF 页 = 书页 + 3，书页编到 285），该文也注明「页码与官方版不一致，引用时别混用」。
- 站内不提供 288 页汉化版页码，也没有官方中文版页码；三种页码不能互相换算（汉化版有重排压缩）。

### 2.4 覆盖差异

- 站内是全集型：2014/2024 核心书、冒险模组、怪物、法术、物品都有数据文件；我们只有 150 词机制映射、PHB 结构复盘与第一章原型。
- 站内可以补我们的空白（法术 / 怪物 / 物品细类、2024 规则），但反过来不能把我们的叫法当成站内叫法用。

## 3. 规则一致性抽查（2014）

| 我方说法 | 站内 PHB（2014）原文要点 | 结论 |
| --- | --- | --- |
| 闪避 = 攻击者劣势 | 可见敌人攻击检定劣势，敏捷豁免优势；失能或速度为 0 时失效 | 一致 |
| 冲刺 = 动作换额外移动 | 额外移动 = 速度 | 一致 |
| 帮助 = 同伴优势 | 下次属性检定或攻击检定优势 | 一致 |
| 准备 = 预设触发 | 触发后用反应执行 | 一致 |
| 躲藏 = 敏捷（隐匿）检定 | 敏捷（隐匿）检定 | 一致 |
| 搜索 = 察觉或调查 | 感知（察觉）或智力（调查） | 一致 |
| 使用物品 = 交互动作 | 一般互动免费；一回合第二个物件要用「使用物件」动作 | 基本一致；「交互动作」措辞偏笼统，可改为「需要动作的物件互动」 |
| 9 个状态 + 豁免按 2014 | 逐条核对，效果描述一致 | 一致（名称见 §2.1） |

## 4. 使用边界

- 站点的 2014 译文是 5e不全书汉化组作品，2024 译文同样为爱好者翻译；原文版权属威世智，翻译内容按 CC BY-NC-SA 4.0 授权、限非商业使用。
- 本项目（[`trpg-rules-survey.md`](trpg-rules-survey.md)）的规则边界是 SRD 5.1：站内译文、表格、数据卡只能做术语对照和规则核对，不复制进产品、不镜像、不再分发、不截图进游戏。
- 引用站内内容时写明「5e不全书汉化组译文，5e.kiwee.top，2014 PHB p.xxx」，不要写成官方中文版。
- 若要把 2024 资源接进游戏，等于换规则版本，需要单独立项，不能和现有 2014 玩法混用。

## 5. 建议

1. **统一词表译名**（低风险、纯文本）：把 §2.1 的 8 个标签改成站内写法，旧叫法在括号里保留为俗称，例如「回避 Dodge（俗称闪避）」；`data/cet4-dnd-vocab.json` 的 `mechanism`、`why`、`use` 同步改。映射：
   - 杂技 → 特技
   - 闪避 → 回避
   - 冲刺 → 疾走
   - 帮助 → 协助
   - 准备 → 预备
   - 使用物品 → 使用物件
   - 恐惧 → 恐慌
   - 失明 → 目盲
2. **文档显式标版本**：5e 相关文档统一写「2014 PHB」；查站内时认 `PHB` 来源，看到「过期资源 ʟ」标记就说明是 2014 条目。
3. **页码**：继续用我们汉化版书页；转引站内时注明英文原版页码，三种页码不混用。
4. **取数**：核对规则原文时读 `/data/*.json`，用 `ENG_name`、`source`、`page` 过滤，不爬页面。
5. **站点价值**：作为 2014/2024 规则与中文术语的机器可读参照，可用来补齐我们没写的法术 / 怪物 / 物品；但只做参照，不入库。

## 6. 核对方法与局限

- 方法：2026-11-10 抓取 `https://5e.kiwee.top/data/{skills,actions,conditionsdiseases,spells-phb,books}.json`、首页与前端脚本，按 `ENG_name` 对照我们 `docs/` 与 `game/` 的术语和规则描述。
- 只核对了与现有资料相关的技能、动作、状态、核心规则词条；没有逐条比对全部法术、怪物、物品与冒险模组。
- 未纳入 5p1ral/TRPGrepo 的 PDF 译文对照：该仓库只作离线参考、不入库（见 [`trpg-rules-survey.md`](trpg-rules-survey.md) §4.5）。
- 站点是「测试Demo版」，译文和条目会继续变；本报告是当天快照，后续引用应复核。
- 未取得威世智官方中文版 PHB，无法判断「官方译名」与站内译名的差异；本文只比较「我方资料 vs 站内数据」。
- 许可信息取自站点页面自述，不构成法律意见。
