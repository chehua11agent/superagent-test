# 单词连连看 · 道具卡解锁（可玩原型）

在「单词连连看」下面加一排被封印盖住的随机道具卡：**连对配对 → 封印松动 → 集满进度自动翻面 → 点「使用」才生效**。

- 线上试玩：<https://chehua11agent.github.io/superagent-test/prototype/linkgame-cards/>
- 本地：直接打开 `index.html`（单文件、零依赖、`file://` 也能跑）

## 这个原型在试什么

道具不是白送的：先用「封印」盖住，靠连连看的配对进度一格一格松开；解锁后才翻面，翻开后才能用。重点试三件事：

1. **被盖住时，你会不会为了开卡多连几对？** 卡背只写还差几对，认不出是哪张，也没法提前用。
2. **集满进度、封印「啪」地翻开那一下爽不爽？** 翻面、闪光、底部提示，都是为这一下服务的。
3. **开出来的卡你舍不舍得用？** 翻开不等于用了，点「使用」才生效；用不用、什么时候用，自己决定。

## 玩法

- 点一个方块，再点它的中英搭档：英文单词 ↔ 中文义项。
- 多义词可以一词多连（bank → 银行、河岸），**每个正确义项都算一对**；一个词的所有义项连完，英文方块才消失。
- 没有中文搭档的英文方块（adopt / quite / principle / carpet / whisper）是干扰项，最后自动清空。
- 每连对一对，下方 3 张道具卡的封印进度一起 +1；分别连够 2 / 3 / 4 对时翻面解锁。
- 翻面后点「使用」生效；每张卡只能用一次。

## 道具（4 种随机抽 3 种）

| 道具 | 效果 |
| --- | --- |
| 透视镜 | 高亮一组还能连的配对 |
| 洗牌器 | 把剩下的方块重新排一遍 |
| 清道夫 | 扫掉一个多余方块 |
| 连锁器 | 自动连掉一组正确配对 |

## 参数（都是占位）

- 3 张卡，随机抽 3 种效果，解锁条件固定为 2 / 3 / 4 对。
- 词表沿用 2026-11-11 群里那份「单词连连看 · 多义一词多连版」原型的 6 个词与 5 个干扰词，方便和原版对照。
- 不接 `game/` 主游戏，不改动现有代码；没有存档，刷新即重开。

## 这版还没做的事

- 没把「解锁条件」和英语学习目标挂钩（例如：用错词、难词来加速某张卡）。这是下一步最值得试的方向。
- 没有做卡池成长、稀有度、跨局保留；目前只是单局演示。
- 没有音效。

Playwright 在 1440×1200 与 390×844 下实际跑过：配对、2/3/4 对解锁、4 种道具效果（用固定随机种子逐一触发）、结算、再来一局、移动端无横向溢出，均通过；截图见 `screenshots/`。
