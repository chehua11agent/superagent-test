# 自适应词汇实验室

一个零依赖的单页原型：把「怎么挑下一个词」拆成三个可分别验证的问题——

1. **生词筛选**：用尽量少的题，估出词汇量，同时把大概率不认识的词找出来；
2. **间隔复习**：熟词不要反复打扰，到期才复习，间隔随记忆稳定性拉长；
3. **遗忘检验**：按遗忘风险排队；答错先次日确认，区分手滑与真遗忘。

在线试玩：<https://chehua11agent.github.io/superagent-test/prototype/adaptive-vocab/>

完整调研、公式出处、仿真设计与接入建议见
[`docs/research/adaptive-vocab-scheduling.md`](../../docs/research/adaptive-vocab-scheduling.md)。

## 运行

不需要安装依赖，也不需要构建。用任意静态服务器打开本目录：

```bash
# 在仓库根目录
python3 -m http.server 4174
# 打开 http://127.0.0.1:4174/prototype/adaptive-vocab/
```

不要用 `file://` 直接打开：页面用了 ES module 与 module worker，浏览器会拦截。

## 页面里有什么

| 区块 | 内容 |
| --- | --- |
| 生词筛选 | 6 种选题策略的词汇量误差曲线；12 题后的「误差 × 生词命中率」取舍图；可调 θ 的 12 题推演 |
| 间隔复习 | 1/3/7/16 固定阶梯 vs FSRS vs 风险分 vs 余量巡检；成本 × 保持率、无效复习、遗忘发现延迟 |
| 巡检曲线 | 强制留 0/10/20/30% 名额给熟词时，保持率与无效复习怎么变 |
| 公式与取舍 | 推送分数、三通道伪代码、FSRS 公式、默认参数、接进现有游戏的最小改法 |

所有数字都由 `sim.js` 在浏览器 Worker 里实时计算，固定种子，可复现。切换「换一组样本」会换种子。

## 仿真模型（诚实说明）

- **词库**：240 个合成词，难度 `b` 由词频分位映射；价值 `v` 随词频升高。
- **学习者**：能力 `θ` 从正态分布抽取；答对率用 3PL：
  `P = 0.2 + 0.8·σ(1.7(θ−b))`，即含 20% 猜对。
- **筛选**：EAP 在 θ 网格上更新后验；前 5 题最大化 Fisher 信息，之后选预测答对率最接近 0.40 的未见词。
- **复习**：真实记忆与算法记忆都走 FSRS-4.5；真实稳定性带隐藏偏差，并偶发遗忘冲击，所以算法模型并不完美。
- **指标**：词汇量 MAE、生词命中率/召回、90 天真实保持率、无效复习占比、遗忘发现延迟、静默遗忘。

这是合成数据仿真，**不是学习效果承诺**。它适合回答“方向对不对、参数大概在哪个区间”，不能替代真实玩家数据。词库难度、FSRS 参数、目标答对率都要在接入后用真实记录重调。

## 已知边界

- 只模拟“认义”一条轨；游戏里的拼写轨、语境、词形变化没有进入模型。
- 生词/熟词用 `b < θ` 的阈值定义，真实学习里“认识”是连续的、受语境影响的。
- “遗忘发现延迟”以真实 `R < 0.7` 为事件起点；答对一次不代表没忘，只是这次没被抓到。
- 巡检只作为“预算有余量时的保险”；仿真里强制留名额会挤掉到期复习，详见调研文档。
- 页面没有后端，不保存任何数据；刷新即重置。

## 接进游戏

调研文档第 4 节给了最小改法：保留 `game/src/srs.js` 的对外函数，新增 FSRS 纯函数；把 `nextNewWords` 的词频排序换成混合选题；复习队列先到期、再巡检；答错先次日确认。先用开关灰度，拿真实数据校准后再替换默认 SRS。
