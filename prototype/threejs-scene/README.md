# 雾港 · 三维小样

《拾词者 · 雾港》的 three.js 场景切片：**一张低多边形港区地图，加 4 个角色和 9 件道具**。这不是完整游戏，是用来确认「3D 建模长什么样、能不能点」的可运行小样。

页面没有构建步骤、没有外部网络请求：three.js r160 已放在 `vendor/`（MIT，许可证见 `vendor/THREE-LICENSE.txt`），其余几何、材质、贴图（木牌上的字、雨棚条纹、太阳光晕）全部在运行时生成。

## 打开

```bash
cd prototype/threejs-scene
python3 -m http.server 8080
# http://127.0.0.1:8080/
```

不要直接双击 `index.html`：页面用的是 ES module + import map，`file://` 会被浏览器拦下。

## 场景里有什么

| 分类 | 数量 | 内容 |
| --- | ---: | --- |
| 地图场景 | 3 | 雾港岛屿（草坡、礁石、路径、草丛）、旧栈桥、冷杉林 |
| 建筑 | 3 | 雾灯旅店（烟囱冒烟、暖窗、手绘招牌）、港口灯塔（旋转光束）、渔市摊位（条纹雨棚、鱼箱） |
| 人物 | 4 | 守夜人、搬运工、鱼贩、港区卫兵 |
| 道具 | 9 | 木桶、板条箱、海员木箱、灯柱、路牌、渔网、小划艇、营火、旅店猫 |

共 **19 件可点选的资产**，约 **12k 三角面**。点击场景里的任何一件，右下角会显示名称、类别、面数和一段建模说明；双击或点「镜头对准」会把镜头移过去。

## 操作

| 操作 | 方式 |
| --- | --- |
| 旋转 / 缩放 / 平移 | 拖拽 / 滚轮或双指 / 右键拖拽 |
| 查看物件 | 单击物件，或打开「资产」清单点条目 |
| 镜头对准 | 双击物件，或卡片里的「镜头对准」 |
| 切换时间 | 黄昏 / 夜晚 / 黎明 |
| 自动环绕 | 「自动旋转」按钮 |
| 回到初始机位 | 「重置视角」按钮，或 `R` |
| 关闭卡片 / 清单 | `Esc` |

移动端把工具栏放到屏幕底部；资产清单和物件卡片会变成底部浮层。

## 三个时间状态

- **黄昏**（默认）：低角度暖色主光、长影、灯笼刚亮。
- **夜晚**：月光、星空、灯塔光束与灯笼成为主光。
- **黎明**：冷蓝天光、低对比、灯笼几乎熄灭。

时间切换是连续插值，不是瞬间换图。

## 程序化建模的边界

- 所有模型都由 three.js 的基本几何体（圆柱、锥体、盒体、球体、圆环、挤出体）拼出来，没有 glTF / 贴图素材，也没有 Blender 文件。
- 木牌、旅店招牌、雨棚条纹、灯芯光晕是 canvas 贴图；灯塔光束是加色混合的锥体。
- 角色共用同一套低多边形骨架分组（髋、躯干、头、四肢），只换材质和配件；守夜人、搬运工、鱼贩、卫兵各有独立的待机 / 行走 / 招手循环。
- 水面是一个径向网格：近岸密、远处疏；外缘在雾里自然消失，所以看不到地图边缘。
- 想快速验证「灰模 vs 材质」的差别，可以在地址后加 `?greybox=1`；想让画面停住截图，加 `?still=1`（页面里另有一个不参与 UI 的调试句柄 `window.__mistHarbor`）。

## 已知边界

- 这是单场景切片：没有碰撞、没有自由行走、没有室内、没有音频。
- 镜头围绕固定焦点旋转，不做第一人称；角色动画是按代码里的时间函数循环，没有动画状态机。
- 没有真实贴图和法线，材质是纯色 + 平直着色；换更写实的方向需要引 glTF 资产与 PBR 贴图。
- 鼠标悬停只改光标，不做高亮描边；触屏没有 hover，需要先点一下。
- 光照按桌面 GPU 调的，低端手机可能掉帧；阴影尺寸在窄屏会自动降到 1024。
