生词筛选 × 间隔复习

一个单页仿真：每次只推进一个词。它要同时做到三件事—— 从词库里快速找出生词，隔着越来越长的间隔复查熟词， 并在遗忘刚发生时把它抓出来。下面每张图都由页面里的算法实时跑出。

① 选择中自动筛生词 ② 间隔检查熟悉词 ③ 快速检验遗忘词

筛选：信息量 × 生词倾向

前 5 题用最大信息量估能力，之后贴着能力边界挑“大概率不认识”的词。12 题内，生词命中率约 —，比“固定 3 词 + 随机”的词汇量误差低约 —。

复习：FSRS 取代固定阶梯

用稳定性 S / 难度 D 预测当前记得的概率 R；R 高就不打扰，R 低才复习。90 天仿真里，复习量少约 —、保持率只差约 — 个百分点，无效复习从 — 降到 —。

巡检：只在预算有余量时做

到期词优先；剩下的名额才抽查熟词。答错先“次日确认”，区分手滑与真遗忘。巡检比例不是越高越好——硬留名额会挤掉到期复习。

用尽量少的题，同时估出词汇量与找出单词

每个点是一名虚拟学习者：词库按词频给出难度，答对率由 3PL 模型生成，答题含 20% 猜对。曲线是 200 名学习者的平均。

为什么前 5 题不直接挑最难的？ 因为还不知道你处在哪个水平。先估出 θ，后面的“难”才有意义。 纯挑最难能 98% 抽到生词，但词汇量误差会明显变差；纯最大信息能把误差压到最低，却只有四到五成是生词。 混合策略取中间：先估准，再贴着边界找。

熟词少打扰，遗忘早发现

90 天、每天 8 个复习名额、40 名虚拟学习者；包含隐藏的记忆偏差与偶发遗忘冲击，所以模型并不完美。复习量按“每词 90 天被复习几次”计。

指标明细

“发现率”= 真实跌破 0.7 的词中，之后被考到并答错的比例；“静默”= 到最后仍低于 0.7 且没被发现的词。

如果硬留巡检名额，会发生什么？

把每天 8 个名额中的一部分固定留给“非到期熟词”。比例越高，熟词被检查得越勤，但到期复习会被挤掉。

结论：到期复习优先，是这套仿真里最稳的策略。固定阶梯的 41% 复习发生在“其实还很熟”的时候； FSRS 把间隔随稳定性拉长（16 天封顶 → 数月），熟词自然被“隔着”检查。 巡检只在名额有余量时做，是保险，不是主策略。

一个推送分数，三个通道

真正要推到玩家面前的词，按状态走不同通道；每个通道内部用同一个“优先级”函数排序。这样既有统一解释，又不会让某一类词饿死。

// 新词：估能力 + 找生词 Push_new(i) = I_i(θ) + λ · (1 − p_i) · v_i // 在学词：按遗忘风险排 Push_due(i) = (1 − R_i) · (1 + α · lapse_i) · v_i // 熟词巡检：很久没见、且模型不确定 Push_audit(i) = β · (t_i / S_i)^γ · (1 + δ · lapse_i) · v_i // 每轮先满足到期队列，剩余名额才巡检 pick = argmax Push_lane(i)

FSRS 的遗忘曲线

R(t, S) = (1 + 19/81 · t / S)^−0.5 // S 天时 R = 0.9 I(r, S) = S / (19/81) · (r^−2 − 1) // 达到目标保持率 r 的间隔

复习成功时 S 变长（间隔效应），失败时 S 缩短；D 记录这个词对你有多难。游戏里只有“对/错”两档，可映射为 FSRS 的 Good / Again。和 1/3/7/16 固定阶梯相比，它不再给所有词同一个 16 天上限，而是让稳定词逐渐拉开到数月。

接进现有游戏的最小改法

  1. 保留 game/src/srs.js 的对外函数，新增 fsrs.js 纯函数：retrievability、intervalFor、fsrsUpdate。旧的 stage 迁移为初始 S：0.5 / 2 / 5 / 10 天。
  2. 换掉 nextNewWords 的纯词频排序：用上面的混合策略选当天新词，并把 vocabEstimate 接到词力；先只替换“探针”，不动剧情内容。
  3. 复习队列先到期、再巡检：到期按 R 升序；剩余名额才按巡检分抽 1–2 个熟词。保留 1/3/7/16 作为开关回退。
  4. 答错先确认：当天标记 suspect，次日复测；复测错才回短间隔，复测对则只轻微缩短 S。
  5. 用真实数据再校准：仿真只能证明方向。上线后用真实答题记录拟合 FSRS 参数，并监控“预测 R vs 实际正确率”的校准曲线。
边界：这是合成数据仿真，不是学习效果承诺。词库难度按词频分位生成，答题模型是 3PL；真实玩家会有语境、疲劳、猜题和母语迁移。 巡检比例、目标答对率、FSRS 参数都需要用真实数据重调。这个页面的作用是先把“方向”跑出来，再决定是否接进游戏。
