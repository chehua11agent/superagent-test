# 5e《玩家手册》中的剧情设定、DM 指引与故事发展盘点

> 对象：`龙与地下城5e玩家手册_上半.pdf` + `_下半.pdf`（各 144 页 PDF，合计 288 页）。
> 本文页码除特别注明外均为**书中印刷页码**；对应 PDF 页 = 书页 + 3。

## 结论

| 关注点 | 有没有 | 一句话 |
| --- | --- | --- |
| 剧情设定 | **有，但只是零散素材** | 世界观、种族/职业/背景的短篇与人物钩子、诸神、位面、100 条饰品；没有战役设定集，也没有任何成品剧情 |
| DM 指引 | **没有成体系的章节** | 只有散落在规则里的「由 DM 裁定 / 设定 DC」提示，以及社交、旅行、休息规则；本书多次把细节推给《城主指南》 |
| 故事发展 | **没有** | 没有冒险模组、章节流程或剧情大纲；只有角色 1–20 级成长，以及「冒险 / 战役」的概念说明 |

一句话：《玩家手册》回答「怎么玩」，不回答「玩什么故事」和「怎么当 DM」。后两者分别在冒险模组和《地下城主指南》（DMG）里；这本书自己也反复指向 DMG。

## 这本书是什么

- 5e《玩家手册》的**非官方中文汉化**（PDF 第 2 页、书内无页码处为制作组与一校、二校名单），不是威世智官方中文版。英文原版 320 页，本版 PDF 288 页、书页编到 285，页码与官方版不一致，引用时别混用。
- 上下两册各 144 页，但**分册点在专长列表中间**：下册第 1 页 = 书页 142。找内容不要按「上册/下册」判断章节。
- PDF 有完整文本层，可直接检索；本次抽查未见扫描缺字。
- 结构：创建角色（书页 7–147）、进行游戏（148–172）、魔法（173–261）、附录（262–285）。

## 一、剧情设定：有的，但都是「设定种子」

1. **序章的世界观（书页 2–4）**：给 D&D 的默认类型定调——中世纪奇幻 + 魔法 + 怪物；所有世界共处一个「多元宇宙」，并点名被遗忘国度、龙枪、灰鹰、浩劫残阳、密斯塔拉、艾伯伦等官方世界；也明确「DM 可以用这些世界之一，或自创世界」。序章还用「鸦阁堡」开场示范了一段 DM 场景描写（石像鬼、吊桥、拱门），是全书最像「成品叙事文本」的片段。
2. **种族章（13–37）**：9 个种族（矮人、精灵、半身人、人类、龙裔、侏儒、半精灵、半兽人、提夫林）。每个种族开头都有一小段小说场景（矮人与精灵、金月远眺奎灵诺斯、瑞吉斯的午后等），后面是氏族/王国、社会结构、宗教、名字表——可以直接当 NPC 与地区设定的模板。
3. **职业章（38–109）**：12 个职业，每个开头一段场景速写，并配「创建 X」的引导问题（力量从哪来、和宗主/修会/导师什么关系）。这些是角色前史钩子，不是剧情线。
4. **个性与背景（110–125）**：9 阵营说明；13 个背景（侍僧、骗子、罪犯、艺人、行会工匠、隐士、贵族、平民英雄、化外之民、智者、水手、士兵、流浪儿），每个都有叙事描述 + 特点/理想/牵绊/缺点四张表。
   - 全章用提卡·维兰与阿提密斯·恩崔立两个范例人物，把出身、阵营、理想、牵绊、缺点逐项拆开讲，**是全书最好的人物小传写作示范**。
   - 每个背景配 8 条特点、各 6 条理想/牵绊/缺点，是现成的「人物即剧情」素材库。
5. **饰品表（138–139）**：d100 共 100 条奇物，既可做角色随身物，也可做随机剧情钩子（例如「写着你不认识语言的日记」「失踪军团成员的勋章」「画着地精的小草图」）。
6. **附录 B 诸神（265–270）**：被遗忘国度、灰鹰、龙枪、艾伯伦、非人种族神系，另附凯尔特/埃及/希腊/北欧四套现实神话神系表，列阵营、建议领域、圣徽。
7. **附录 C 位面（271–274）**：物质位面、妖精荒野、堕影冥界、正负位面、以太/星界、元素位面与元素混沌、对应 9 阵营的 16 个外层位面、印记城/外域/门镇、半位面。适合做「异界任务」与世界观分层。
8. **附录 E 书单（283–285）**：Gygax 原书单 + 后世奇幻作品，几十位作家，是奇幻灵感来源，不是设定。
9. **法术文本里的设定碎片（173–261）**：主体是规则，但个别法术带世界观信息（如哈达之臂/哈达之欲提到「乌黯之饥渴」）。量少，不成体系。

> 注意：以上都是**设定层**。本书没有「某个世界正在发生什么」的战役设定、没有地区详述、没有势力关系图，也没有任何一段可跑的剧情。

## 二、DM 指引：没有成体系的 DM 章

书里确实有「DM 要做什么」的内容，但都是碎片：

- **序章「如何进行游戏」（3）**：游戏三步循环——DM 描述环境 → 玩家声明行动 → DM 判定并描述结果；「冒险三要素」探索/社交/战斗；把一场冒险比作电视剧一季、战役比作整部剧（4）。
- **第 7 章（148–154）**：何时要求检定、DC 由 DM 设定、被动检定、团队检定、优势/劣势的裁量。
- **第 8 章（155–162）**：
  - 旅行（步调表、困难地形、行军/队列、导航/绘图/追踪/觅食）；
  - 环境（极寒、强风、黑暗等）；
  - **社交（159–160）**：NPC 态度分友好/冷漠/敌对；扮演 + 魅力检定；这是全书最接近「交涉玩法」的一节；
  - 休息与「冒险之余」（生活方式、专业实践、休整、研究、训练）。
- **第 9 章（163–172）**：战斗流程、突袭判定、位置、掩体、即兴动作。
- **第 4 章「激励」（113）**：DM 视情况发放的奖励规则，用来奖励按理想/牵绊/缺点行动。
- **零散的「和 DM 商量」**：邪术师宗主契约（95）、贵族头衔（121）、变体规则（自定义属性 9、负重 151）等。
- **本书自己把 DM 细节推给《城主指南》**：特殊坐骑与旅行步调（155）、迷路/追踪/觅食的详细规则（156）、破誓圣武士（74）、死亡领域（265）都写明「详见《城主指南》」。

**明确没有**：遭遇与战斗设计、怪物图鉴（附录 D 只有 15 种野兽/魔宠数据）、剧情编织、NPC 设计、战役管理、奖励与魔法物品分配、随机事件表。这些正是 DMG 和冒险模组的内容。

## 三、故事发展：没有

- 没有冒险模组、没有章节/场景/幕的流程，也没有剧情大纲或线索结构。
- 唯一的「发展」是**角色等级 1–20**（升级表 10–12）与「冒险/战役」的概念：序章明说「游戏并没有真正的结局」，一段故事结束后另一段开始，战役可持续数月数年。
- 第 1 章「高于 1 级」（10–12）给了四个阶段：1–4 级管地方、5–10 级管城市王国、11–16 级管区域大陆、17–20 级影响世界与多元宇宙。这是**格局曲线**，可当故事难度的刻度，但不是剧情。
- 第 8 章标题叫「冒险」，内容却是时间、移动、环境、休息规则——是「冒险怎么进行」，不是「冒险发生什么」。

## 四、对《拾词者》项目的可用性

能借的（只借概念与结构，不抄文本）：

| 书中内容 | 可怎么用 |
| --- | --- |
| 三要素：探索/社交/战斗（4） | 给「词即行动」分类，三类行动对应三套判定 |
| 游戏三步循环（3） | 对应「词行动 → 判定 → 结果」的节拍 |
| NPC 三态度 + 社交检定（159–160） | 对话/说服/威吓玩法的底层 |
| 激励：理想/牵绊/缺点（113） | 用角色动机驱动复习与行动，而不是纯积分 |
| 背景四张表（113–125）＋ 饰品 d100（138–139） | 角色创建与随机事件钩子 |
| 四阶段格局（10–12） | 12 幕的难度与格局升级曲线 |
| 诸神/位面（265–274） | 世界观只取「多元宇宙 + 位面」的概念，不搬神名 |

借不了的：现成剧情、遭遇数值、DM 运行指南、怪物数据、战役管理。这些要么自己写，要么参考 DMG/冒险模组。
