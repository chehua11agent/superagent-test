# 词咒 · 雾港检定（d20 × 单词识别）

一个零依赖的单页原型：**单词识别只提升 d20 的成功率，不决定结果**。词库随游戏前中后期轮换，词答对到一定次数后会「记忆撤出」，回访答错再回池。

完整调研与机制说明见 [`docs/design/d20-vocab-check.md`](../../docs/design/d20-vocab-check.md)。

## 在线试玩

<https://chehua11agent.github.io/superagent-test/prototype/d20-vocab/>

## 运行

不需要构建，也不需要安装依赖；用任意静态服务器打开本目录：

```bash
# 在仓库根目录
python3 -m http.server 4174
# 打开 http://127.0.0.1:4174/prototype/d20-vocab/
```

不要直接双击 `index.html`（`file://` 下部分浏览器会限制脚本）。

## 一局里会看到什么

| 区块 | 内容 |
| --- | --- |
| 词灵卡 | 英文 + 音标 + 4 个中文义项；5 秒内 +3、9 秒内 +2、12 秒内 +1、答错/超时 +0 |
| 检定 | `d20 + 属性 + 词力 vs DC`；天然 1 必败、天然 20 必成 |
| 概率面板 | 检定前显示「基础成功率 → 词力上限后」，让玩家预期单词值多少 |
| 阶段 | 前期抽高频词、偏好熟词；中期中频；后期低频、偏好生疏词，DC 与干扰项一起变难 |
| 词灵池 | 当前可抽的词与掌握度；答对 3 次后移入「已撤出」 |
| 已撤出 | 封存的词，几幕之后回访；回访答错立刻回池 |
| 结算 | 靠词力翻盘的次数、有词力仍失败的次数、词汇画像与下一局建议词带 |

右上角「词力加成」关掉就是**纯 d20 对照组**：同一场景、同一 DC，可以自己感受单词到底值多少。

## 数值一览（都在 `app.js` 顶部）

- 词力：≤5s +3 / ≤9s +2 / ≤12s +1 / 错或超时 +0
- 属性：+1–+3；DC：10–18
- 撤出：mastery 3；回访：撤出后 3 幕；回访答错：mastery 2 回池
- 能力值：`P = 0.25 + 0.75·sigmoid(1.7(θ−b))`，`θ += 0.55·(对−P)`
- 词汇量：4530 词按 `b(r) = −1.5 + 3.0·(r/4529)^0.8` 铺开，求和后取 θ±0.3 区间

## 已知边界

- 48 个词只是第一章核心词，词汇量是原型级粗估，不是测评结论。
- 只测「认义」；拼写、听辨、语境没有进入 d20 因子。
- 抽词由游戏阶段决定词带；玩家能力值目前只影响结算建议，不影响本局抽词。
- 没有后端与存档；刷新即重开。
