# 灰烬岗哨 · THE ASHEN WATCH

一个**单独成立**的 D&D 5e（SRD 5.1）玩法演示：不背单词，不接别的玩法，用一幕原创剧本把跑团的五个主要环节各走一遍。

> 试玩：<https://chehua11agent.github.io/superagent-test/prototype/ashen-watch/>
>
> 剧本全文：[`scenario.md`](scenario.md) · 规则摘要：[`game.js`](game.js) 里的「规则书」，或页内右上角「规则书」。

## 这一局在演示什么

| 环节 | 这一局里怎么发生 | 用到的规则 |
| --- | --- | --- |
| **探索** | 岗哨外三处调查点：大门、崖边拖痕、焦尸；两处就能进 | 调查 / 生存 / 运动检定；侧窗塌陷的敏捷豁免 |
| **社交** | 受伤的守夜人艾达用长矛指着你们；说服、洞悉、威吓、出示村徽 | NPC 态度；说服 / 洞悉 / 威吓检定；失败也有代价 |
| **战斗** | 灰烬骑士 + 两只灰烬猎犬；三人小队 + 可能的盟友艾达 | 先攻、AC、攻击检定、伤害骰、暴击、优势 / 劣势、群战优势、法师法术位、死亡豁免 |
| **短休** | 点起烽火后休息一小时：花生命骰、回气、奥术恢复 | 生命骰、短休资源恢复 |
| **成长** | 战利品、2,700 XP、全队升到 4 级、属性提升 | XP / 等级 / 属性值提升（ASI） |

大约 8–10 分钟。手机与桌面均可玩。

## 怎么玩

- 剧情里点选项；带 **DC** 的选项会掷 d20，结果卡会显示骰面、加值和成败。失败通常只是换一条代价，不会卡住。
- 战斗里每人一个回合：点敌人卡切换目标，再选攻击 / 法术 / 闪避 / 药水 / 火油。`d20 + 命中加值 vs AC`，命中后掷伤害；20 暴击，1 必失。
- 0 HP 会进入死亡豁免：每回合自动掷 d20，10+ 成功，三次成功稳定，三次失败死亡；20 回 1 HP，1 记两次失败。
- 短休时每名角色可以花一个生命骰；法师还能用奥术恢复换回 1 个法术位。
- 桌面数字键 `1`–`9` 可以选剧情选项；规则书在右上角。

## 为什么是 SRD 5.1，不是那份《玩家手册》

- 《玩家手册》中文版是民间汉化，文本与排版版权不属于我们；不能把译文、表格、法术描述复制进产品。
- **SRD 5.1** 是 Wizards of the Coast 按 CC-BY-4.0 开放的规则文本，可以合法使用其中的机制与术语。本演示只写规则摘要，不复制原文。
- 剧本、角色、地名、对话、画面均为原创；没有使用 WotC 的官方美术或标志。
- 「D&D / 龙与地下城」是 WotC 的商标；这里只用它说明规则风格，不声称官方授权。

## 已知边界（诚实说明）

- **只有一幕。** 3 名预设角色、1 条主线和几条社交分支；没有角色创建、职业选择、法术列表、装备商店、多场战斗或战役。
- **站位是抽象的。** 没有格子 / 距离 / 掩体；「目标身边有队友」用队伍是否有人站着的近似规则代替。
- **升级是压缩的。** 任务 XP 一次性发到 2,700，全队升 4 级；属性提升自动加在主属性上，没有让玩家做 ASI 选择。
- **数值只调了一轮。** 目的是让演示能打完、能看见每个环节，不是平衡性结论。
- **玩家控制三名角色。** 这是为了在一场演示里看见完整的先攻与队伍配合；正式跑团通常一人一角色。
- **没有存档、没有多人、没有 DM 模式。** 这是演示，不是成品。
- **没有使用《玩家手册》文本。** 规则摘要基于 SRD 5.1；剧本原创。
