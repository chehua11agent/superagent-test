# 凡戴尔的失落矿坑 · 3D 桌面切片

《凡戴尔的失落矿坑》（Lost Mine of Phandelver）开场段的 3D 桌面切片：**背景故事开场 → 选人动画 → 三猪小径哥布林伏击 → 克拉格巢穴入口**。不是完整模组，是把开场结构做成可玩的一段。

> 参考：用户提供的 LMoP PDF（仅用于核对开场结构、角色与遭遇；PDF 不随本页分发）
> 规则：SRD 5.1（CC-BY-4.0）；文本、模型与画面为本切片原创改写，不使用官方美术。

## 打开

```bash
cd prototype/lost-mine
python3 -m http.server 8080
# http://127.0.0.1:8080/
```

无构建；three.js r160 在 `vendor/`（MIT，见许可证）。

## 这一版的流程

1. **开场故事**（5 拍，可跳过）
   - 剑湾北地 / 无冬城短笺 / 三猪小径 / 两匹死马 / 树影里的眼睛。
   - 3D 背景随文本换机位；雨、马车、死马、树影里的哥布林眼睛；信件卡入场动画。
2. **选人动画**
   - 四名 Starter Set 风格的预生成角色：达尔文（人类战士）、巴文（轻足半身人游荡者）、布鲁诺（丘陵矮人牧师）、阿拉米尔（高等精灵法师）。
   - 点卡片或点桌面上的 3D 模型；选 3 名。模型会亮环、转向、前移。
3. **三猪小径分支探索地图**
   - 不是战斗棋盘：起点 → 两匹死马 / 路旁浅溪 → 树影 / 翻倒的补给车 / 崖壁捷径 → 克拉格巢穴。点相邻节点，走到哪里就触发哪个事件；树影节点进入战斗。
   - 事件：调查马尸、生存浅溪、补给车 loot、运动崖壁、察觉树影。成功 / 失败改变线索与战斗条件。
   - 战斗仍按 5e theater of mind：4 只克拉格哥布林（HP 7 / AC 15 / 短弓 +4）；没有移动格 / 掩体格。
   - 3D 骰子或单词检定、手牌、先攻、优势 / 劣势、治疗、隐匿、协助、祝福、魔法飞弹、死亡豁免。
4. **短休 / 克拉格巢穴入口**
   - 战斗结束后短休，沿拖痕到岩壁裂口；第一幕结束，下一段留给完整切片。

## 单词检定（替代 d20）

- 手牌区「检定 · 单词 / d20」可切换；默认 **单词**。
- 词库 30 个场景词；牌堆抽 20 张，每张随机分到 1–20 的**词卡面值**，洗牌。
- 检定：抽一张，选正确中文词义。4 秒内对 **+3**，8 秒内对 **+2**，错 **-2**，超时 **-3**。
- 结果 = 词卡面值 + 词义修正 + 属性调整值，对抗 DC / AC。
- 优势抽两张取高面值，劣势取低；只问一张的单词。
- 随机性来自词卡面值、抽词、选项顺序、干扰项；认识单词提高结果，但低面值仍可能失败，不认识也可能靠高面值成功。
- 敌人攻击 / 死亡豁免默认用 d20，避免替 DM 答题。

## 操作

- 开场：继续 / 跳过；选人：点卡片或桌面模型，选 3 名后出发。
- 桌面：拖拽旋转、滚轮缩放；点哥布林切换目标，点角色看说明。
- 右上 **环境** 循环：晨雾 / 阴雨 / 黄昏 / 夜。
- 规则书、重置视角、重开。
- 移动端 390 竖屏：开场、选人 2×2 卡片、HUD 手牌与剧情面板均有适配。

## 技能 / 资产

- **`create-game-assets`**：程序化低多边形资产（森林、马车、死马、哥布林、四名角色、洞穴入口）；无第三方模型 / 贴图。
- **`game-feel`**：选人亮环 / 转向、骰子落桌、挥砍与箭矢、命中震动、飘字。
- **`rpg`**：5e 检定 / 先攻 / AC / 优势 / 死亡豁免 / 短休；**`game-ui-ux`**：开场、选人、HUD 与移动端布局。

## 已知边界

- 只有**开场一段**：三猪小径 + 巢穴门口；没有 Cragmaw Hideout 内部、凡达林、红烙印、Wave Echo Cave。
- 4 名角色中选 3 名（模组建议 4–5 人；切片降低操作量）；哥布林按模组数量 4 只，难度偏高。
- 没有格子 / 掩体 / 存档 / 多人 / DM 模式；场景是切面，不是自由行走地图。
- 角色 / 怪物为程序化低多边形；低端手机可能掉帧（`?qa=1` 关闭阴影，仅供调试）。
- 未接入正式游戏；这是方向确认用的开场切片。
